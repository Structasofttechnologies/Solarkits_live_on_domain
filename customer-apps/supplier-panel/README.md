# Emergesun Supplier Panel Frontend

Supplier interface for component inventory, pricing catalogs, and procurement quotes management within the Emergesun Project ecosystem.

## 🚀 Features
- **Supplier Dashboard**: View active purchase orders and quote requests.
- **Inventory Catalog**: Manage and update components, pricing, and availability.
- **Interactive UI**: Modern interface built using React and Tailwind CSS v4.
- **State Management**: Redux Toolkit integration for session persistent data.

## 🛠️ Tech Stack
- **React 19** & **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **React Router** & Redux Toolkit

## ⚙️ Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
The application will run on `http://localhost:5181`.

## 🔗 Integration
This application connects to the Supplier Backend for data management. It can be accessed locally at port `5181` and is integrated within the ecosystem network.
