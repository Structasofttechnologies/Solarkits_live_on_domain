# SolarKits Solar Shop India Frontend

Customer-facing e-commerce platform for solar products and services in India.

## 🚀 Features
- **Product Catalog**: Dynamic browsing of solar components and systems.
- **Interactive Charts**: Data visualization using Recharts for energy savings.
- **Modern UI**: Sleek, high-performance interface built with Tailwind CSS v4.
- **Smooth UX**: Fluid interactions and animations via Framer Motion.

## 🛠️ Tech Stack
- **React 19** & **Vite**
- **Tailwind CSS v4**
- **Framer Motion**
- **Recharts**
- **Redux Toolkit**

## ⚙️ Development
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
The application will run on `http://localhost:5177` (default).

## 🔗 Integration
This application connects to the Solar Shop Backend for data and authentication. In a production or integrated local setup, it should be configured within the Nginx reverse proxy.
